# Календарик стукача

Статический проект для GitHub Pages.

## Как опубликовать

1. Распакуйте архив.
2. Загрузите `index.html`, `manifest.webmanifest`, `sw.js` и папку `icons` в корень репозитория.
3. В GitHub откройте **Settings → Pages**.
4. Выберите ветку `main` и папку `/root`.
5. Сохраните настройки.

## Что исправлено в этой версии

- Переписано сохранение записей: новые записи добавляются к выбранному дню, а не перезаписывают старые.
- Добавлен новый storage-ключ `kalendrik-stukacha-yakovlev-v3` с миграцией старых данных.
- Добавлена кнопка **Сбросить кэш**.
- Добавлен `sw.js`, который очищает старые PWA/service worker кэши и сразу отключает себя.
- Добавлена проверка `localStorage` и вывод статуса хранения в интерфейсе.

## Если после обновления всё ещё открывается старая версия

1. Нажмите **Сбросить кэш** внутри приложения.
2. Обновите страницу с очисткой кэша: `Ctrl+F5` на Windows или `Cmd+Shift+R` на macOS.
3. На iPhone удалите старую иконку с главного экрана и добавьте сайт заново через Safari.
