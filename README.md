# Календарик стукача

Статический проект для GitHub Pages. Сервер, база данных и сборка не нужны.

## Что исправлено

- Сохранение теперь не перезаписывает записи за день: на одну дату можно добавлять любое количество пропусков.
- Перед сохранением приложение перечитывает данные из хранилища браузера, чтобы не терять уже добавленные записи.
- Добавлен блок «Все записи месяца», чтобы сразу видеть, что все пропуски сохранились.
- Сохранены PWA-иконки для iOS, Windows и браузеров.

## Публикация на GitHub Pages

1. Распакуйте архив.
2. Загрузите содержимое папки `kalendrik-stukacha` в корень репозитория.
3. В GitHub откройте `Settings` → `Pages`.
4. Включите публикацию из ветки `main`, папка `/root`.
5. Откройте выданную ссылку Pages.

## Файлы

- `index.html` — приложение.
- `manifest.webmanifest` — настройки PWA.
- `icons/` — иконки для iOS, Windows и браузеров.
