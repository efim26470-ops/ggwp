# Календарик стукача

Статический HTML-проект для GitHub Pages. Данные хранятся только локально в браузере через `localStorage`, сервер и база данных не нужны.


## Функции

- Календарь по месяцам.
- Рабочее время: будни 10:00–17:00, суббота 10:00–14:00.
- Воскресенье отключено как выходной.
- Интервалы с точностью до минуты через `time`-поле и кнопки `+/-`.
- Причины пропуска: готовые варианты + собственная причина.
- Локальное хранение записей по дням.
- Редактирование и удаление записей.
- Сводка по выбранному дню и месяцу.
- Экспорт CSV, экспорт/импорт JSON.
- Тёмная, светлая и офисная темы.

## Важно

Так как используется локальное хранение, данные сохраняются только в конкретном браузере и на конкретном устройстве. Для переноса используйте экспорт/импорт JSON.
